# PLAN — คลื่นไทย (khlun-thai)

เว็บฟังวิทยุออนไลน์ทุกประเทศ ใช้ข้อมูลจาก [Radio Browser API](https://api.radio-browser.info/)
ไฟล์นี้คือแผนงานหลักสำหรับ AI agent ใน VS Code ให้ทำทีละขั้นตามลำดับ และหยุดให้ผู้ดูแลตรวจหลังจบแต่ละขั้น

---

## 1. บริบท

- ต้นแบบอยู่ที่ `reference/khlun-thai-radio.html` เป็นเว็บวิทยุไทยไฟล์เดียว ใช้อ้างอิงเรื่องหน้าตาและพฤติกรรม
- สิ่งที่ต้องคงไว้จากต้นแบบ:
  - หน้าปัด FM 87.5–108 MHz ที่มีเข็มเลื่อนไปตามสถานีที่เล่น และกดจุดสถานีบนหน้าปัดเพื่อเล่นได้
  - แถบควบคุมด้านล่าง: เล่น/หยุด, ก่อนหน้า/ถัดไป, ปรับเสียง, ลิงก์เว็บสถานี
  - เล่น HLS (.m3u8) ผ่าน hls.js และใช้ของเบราว์เซอร์เองถ้ารองรับ (Safari)
  - Media Session (ปุ่มบนหน้าจอล็อกของมือถือ)
  - ธีมสว่าง/มืดผ่าน CSS tokens ตามที่เครื่องตั้งไว้
  - ฟอนต์ Chakra Petch (หัวข้อ), IBM Plex Sans Thai (เนื้อหา), IBM Plex Mono (ตัวเลข/ความถี่)
  - UI ภาษาไทยทั้งหมด

## 2. เป้าหมาย

- แสดงสถานีวิทยุของทุกประเทศที่มีข้อมูลใน Radio Browser
- เรียงสถานีตามความนิยม (clickcount) จากมากไปน้อย
- มีตารางธงประเทศให้กดเลือก แล้วแสดงสถานีของประเทศนั้น
- แบ่งหน้า (30 สถานีต่อหน้า) พร้อมตัวเลือกหน้า
- กดการ์ดสถานีแล้วเล่นทันที

## 3. Stack และข้อกำหนดทางเทคนิค

| เรื่อง | กำหนด |
|---|---|
| Build tool | Vite (ล่าสุด) |
| ภาษา | vanilla JavaScript แบบ ES modules ไม่ใช้ framework UI |
| ธงประเทศ | แพ็กเกจ npm `flag-icons` (SVG) ห้ามใช้ emoji ธง เพราะ Windows แสดงไม่ได้ |
| HLS | แพ็กเกจ npm `hls.js` |
| ชื่อประเทศภาษาไทย | `new Intl.DisplayNames(['th'], { type: 'region' })` ถ้าไม่มีชื่อ ให้ใช้ชื่อจาก API |
| การจัดเก็บฝั่งเบราว์เซอร์ | `localStorage` ครอบ try/catch ทุกครั้ง ถ้าใช้ไม่ได้หน้าเว็บต้องทำงานต่อได้ |

## 4. การใช้ Radio Browser API

### เลือกเซิร์ฟเวอร์ (api.js)
1. โหลดรายชื่อ mirror จาก `https://all.api.radio-browser.info/json/servers` แล้วสุ่มเลือก 1 ตัว
2. ถ้า request ล้มเหลว (network error หรือ status 5xx) ให้สลับไป mirror ถัดไปอัตโนมัติ
3. ถ้าโหลดรายชื่อ mirror ไม่ได้ ให้ใช้ `de1`, `nl1`, `at1` `.api.radio-browser.info` แทน
4. ห้าม hardcode เซิร์ฟเวอร์ตัวเดียว

### Endpoint ที่ใช้

| งาน | Endpoint |
|---|---|
| รายชื่อประเทศ | `GET /json/countries` |
| สถานีตามประเทศ | `GET /json/stations/search?countrycode={CC}&order=clickcount&reverse=true&hidebroken=true&limit=30&offset={(page-1)*30}` |
| กรองตาม tag | เพิ่ม `&tag={tag}` ใน search ข้างบน |
| ค้นหาตามชื่อ | `GET /json/stations/search?name={q}&order=clickcount&reverse=true&hidebroken=true&limit=30` (เพิ่ม `countrycode` ถ้าค้นเฉพาะประเทศ) |
| แนวเพลงยอดนิยม | `GET /json/tags?order=stationcount&reverse=true&limit=30` |
| **กดเล่น (นับคลิก)** | `GET /json/url/{stationuuid}` |

### กฎสำคัญ
- **ทุกครั้งที่กดเล่น ต้องเรียก `/json/url/{stationuuid}` ก่อน** เพื่อนับยอดคลิกให้สถานี (เป็นมารยาทที่ Radio Browser ขอ) แล้วใช้ `url` ที่ได้กลับมาเล่น ถ้าเรียกไม่สำเร็จให้ใช้ `url_resolved` จากข้อมูลสถานีแทน
- ประเทศ: ใช้เฉพาะ `stationcount > 0` เรียงจากมากไปน้อย, cache ใน localStorage 24 ชั่วโมง
- สถานี: cache ผลแต่ละหน้าในหน่วยความจำ (key = ประเทศ + tag + หน้า)
- จำนวนหน้าทั้งหมด = `ceil(stationcount / 30)` จากข้อมูลประเทศ ถ้ากรอง tag อยู่ (ซึ่งไม่รู้จำนวนรวม) ให้แสดงปุ่ม "ถัดไป" จนกว่าจะได้ผลน้อยกว่า 30
- ตัด field ที่ใช้ให้เหลือแค่ `stationuuid, name, url_resolved, homepage, favicon, tags, countrycode, codec, bitrate, hls, clickcount, lastcheckok`

## 5. หน้าเว็บ

### ลำดับส่วนประกอบ (บนลงล่าง)
1. **หัวเว็บ** — ชื่อ "คลื่นไทย", ธง + ชื่อประเทศที่เลือกอยู่, จำนวนสถานี
2. **หน้าปัด FM** — เหมือนต้นแบบ แสดงความถี่ที่อ่านได้จากชื่อ (`freq.js`) ถ้าอ่านไม่ได้แสดง `NET`
3. **แท็บ** — สถานี | ★ โปรด | ฟังล่าสุด
4. **ช่องค้นหาสถานี** + สวิตช์ "เฉพาะประเทศนี้ / ทุกประเทศ" (debounce 300ms)
5. **chips แนวเพลง** (tag ยอดนิยม)
6. **รายการการ์ดสถานี** — grid ปรับคอลัมน์ตามความกว้าง
7. **ตัวแบ่งหน้า**
8. **ตารางธงประเทศ** + ช่องค้นหาประเทศ
9. **เครดิต** — "ข้อมูลสถานีจาก Radio Browser (radio-browser.info)"
10. **แถบควบคุม** fixed ด้านล่าง

### การ์ดสถานี
- โลโก้จาก `favicon` (lazy load) ถ้าว่าง/โหลดไม่ได้/เป็น http บนหน้า https → แสดงวงกลมพร้อมตัวอักษรแรกของชื่อ
- ชื่อสถานี (ตัดบรรทัดได้ ห้ามล้นการ์ด)
- tags ไม่เกิน 3 อัน
- codec · bitrate · จำนวนคลิก (รูปแบบ 12.3k)
- ป้าย `http` สีเตือน ถ้าสตรีมไม่ใช่ https
- ปุ่ม ☆/★ สถานีโปรด
- สถานีที่กำลังเล่น: ขอบสีเข็มเหมือนต้นแบบ
- ทั้งการ์ดเป็นปุ่ม (Enter/Space เล่นได้)

### ตัวแบ่งหน้า
- `‹ ก่อนหน้า` · `1 … 4 5 [6] 7 8 … 120` · `ถัดไป ›`
- ช่องพิมพ์เลขหน้าแล้วกด Enter
- เปลี่ยนหน้าแล้วเลื่อนกลับไปต้นรายการ

### ตารางธงประเทศ
- เรียงตามจำนวนสถานี แสดงธง ชื่อไทย และจำนวนสถานี
- ค้นหาได้ทั้งชื่อไทย ชื่ออังกฤษ และรหัส 2 หลัก (เช่น "jp", "ญี่ปุ่น", "japan")
- แสดง 48 ประเทศแรก + ปุ่ม "แสดงทั้งหมด"
- กดธง → โหลดหน้า 1 ของประเทศนั้น และเลื่อนขึ้นบนสุด

### การเล่น
- กดการ์ด → เล่นทันที (เรียก `/json/url/{uuid}` ก่อนตามกฎ)
- สถานี `hls: 1` หรือ URL ลงท้าย `.m3u8` → ใช้ hls.js (หรือ native บน Safari)
- ก่อนหน้า/ถัดไป → เลื่อนในรายการหน้าปัจจุบัน ถ้าสุดหน้าให้โหลดหน้าถัดไป/ก่อนหน้า
- ถ้าเปิดหน้าเว็บผ่าน https และสตรีมเป็น http → เล่นผ่าน `PROXY_BASE + stationuuid` (ค่าเริ่มต้น `/stream/`, ตั้งค่าได้ใน `config.js`; ถ้า `PROXY_BASE` เป็นค่าว่าง ให้ถือว่าไม่มี proxy และแสดงการ์ดพวกนั้นแบบจาง)
- ข้อความสถานะ:
  - กำลังเชื่อมต่อ… / กำลังบัฟเฟอร์… / กำลังออกอากาศ / หยุดชั่วคราว
  - error ต้องบอกสาเหตุ: "สถานีออฟไลน์ ลองสถานีอื่น", "สตรีม http ถูกบล็อกบนหน้า https", "เซิร์ฟเวอร์เต็มชั่วคราว ลองใหม่อีกครั้ง" (proxy ตอบ 503/429)

### Routing (router.js)
- รูปแบบ hash: `#th` (หน้า 1), `#jp/3`, `#fav`, `#recent`
- ปุ่ม back/forward ของเบราว์เซอร์ต้องทำงาน
- เปิดลิงก์ตรงแล้วได้หน้าเดียวกัน
- ถ้าไม่มี hash → เดาประเทศจาก `navigator.language` (เช่น `th-TH` → TH) หรือ timezone ถ้าเดาไม่ได้ใช้ TH

### สถานีโปรดและฟังล่าสุด (store.js)
- เก็บด้วย `stationuuid` พร้อม snapshot `{ name, countrycode, favicon, url_resolved, codec, bitrate, hls }` เพื่อให้แสดงได้โดยไม่ต้องเรียก API
- ฟังล่าสุด: เก็บ 20 รายการล่าสุด ไม่ซ้ำ
- จำค่าระดับเสียงและประเทศล่าสุดด้วย

## 6. คุณภาพ

- ใช้คีย์บอร์ดได้ทุกปุ่ม มี focus ที่มองเห็นชัด
- คีย์ลัด: Space = เล่น/หยุด, ← → = สถานีก่อนหน้า/ถัดไป (ยกเว้นตอนพิมพ์ในช่องค้นหา)
- เคารพ `prefers-reduced-motion`
- ใช้งานได้ดีที่ความกว้าง 400px ห้ามมี scroll แนวนอน
- ตัวเลขใช้ `font-variant-numeric: tabular-nums`
- loading state: skeleton การ์ดระหว่างโหลด
- empty state: "ยังไม่มีสถานีโปรด กด ☆ ที่การ์ดเพื่อเพิ่ม", "ไม่พบสถานีที่ตรงกับคำค้น"
- error state ตอนโหลด API ไม่ได้: ข้อความ + ปุ่ม "ลองใหม่"
- unit test (Vitest) สำหรับ `freq.js`, `router.js`, `store.js` และฟังก์ชันสร้างเลขหน้า

## 7. ขั้นตอนการทำงาน

ทำทีละขั้น จบแต่ละขั้นให้ **หยุดและสรุปสิ่งที่ทำ + วิธีทดสอบ** แล้วรอคำสั่งไปขั้นถัดไป

### ขั้น 1 — Scaffold
- สร้างโปรเจกต์ Vite, ติดตั้ง `hls.js`, `flag-icons`, `vitest`
- ย้าย CSS tokens, ฟอนต์, หน้าปัด และแถบควบคุมจากต้นแบบเข้าโครงสร้างใหม่
- ใช้ข้อมูลตัวอย่าง 5 สถานีชั่วคราวเพื่อให้หน้าเว็บเล่นได้
- **ผ่านเมื่อ:** `npm run dev` แล้วหน้าตาเหมือนต้นแบบ และเล่นสถานีตัวอย่างได้

### ขั้น 2 — API + ตารางธงประเทศ
- `api.js` (เลือก mirror + fallback + cache), `/json/countries`, ชื่อไทย, ตารางธง, ค้นหาประเทศ
- **ผ่านเมื่อ:** ธงแสดงครบไม่มีรูปแตก, ค้น "jap", "ญี่ปุ่น", "jp" เจอญี่ปุ่น, ปิดเน็ตแล้วรีเฟรชยังเห็นรายชื่อประเทศจาก cache

### ขั้น 3 — รายการสถานี + แบ่งหน้า + เล่น
- โหลดสถานีตามประเทศเรียงตาม clickcount, การ์ด, ตัวแบ่งหน้า, เล่นผ่าน `/json/url/{uuid}`, prev/next ข้ามหน้า, `freq.js` กับหน้าปัด
- **ผ่านเมื่อ:** กดการ์ดแล้วเล่นทันที, F12 → Network เห็น request `/json/url/...`, เปลี่ยนหน้าได้, สถานี HLS เล่นได้, ข้อความ error ตรงสาเหตุ

### ขั้น 4 — Routing, โปรด, ค้นหา, tag
- router, store, แท็บโปรด/ล่าสุด, ค้นหาสถานี, chips แนวเพลง, เดาประเทศเริ่มต้น, คีย์ลัด
- **ผ่านเมื่อ:** เปิด `#jp/2` ตรงๆ ได้, back/forward ทำงาน, รีเฟรชแล้วสถานีโปรดยังอยู่, `npm test` ผ่าน

### ขั้น 5 — Stream proxy
- ทำตาม `docs/PROXY.md` (เป็นแผนแยก มีขั้นย่อยของตัวเอง)

### ขั้น 6 — เอกสารและ GitHub
- `.gitignore` (Node, OS, `.env`), `LICENSE` (MIT)
- `README.md` ภาษาไทย: ภาพรวม, วิธีรัน dev/build/test, การตั้ง `PROXY_BASE`, วิธี deploy (GitHub Pages และ Docker), เครดิต Radio Browser, หมายเหตุลิขสิทธิ์ (เนื้อหาเป็นของแต่ละสถานี โปรเจกต์นี้ลิงก์ไปยังสตรีมสาธารณะเท่านั้น)
- `.github/workflows/pages.yml`: build แล้ว deploy `dist/` ขึ้น GitHub Pages (ตั้ง `base` ของ Vite ให้ตรงชื่อ repo, `PROXY_BASE` เป็นค่าว่างเพราะ Pages ไม่มี proxy)
- `.github/workflows/ci.yml`: รัน `npm ci`, `npm test`, `npm run build` ทุก push/PR
- **ผ่านเมื่อ:** ทำตาม README บนโฟลเดอร์ใหม่แล้วรันได้จริง
